# Usage

## 0. 启动方式与三种组合

三个 EXE 都没有传统主界面。双击后程序会隐藏到 Windows 任务栏右下角；没有看到时，请展开“显示隐藏的图标”。

- 右键托盘图标打开功能菜单。
- 双击 AirType 图标查看状态。
- 双击 Wireless 或 DirectADB 图标，在浏览器中打开电脑本机设置页面。

推荐按需求选择：只用 AirType；AirType + Wireless 连接无线调试真机；或 AirType + DirectADB 连接雷电、网易 MuMu 等模拟器及 USB 调试真机。

## 1. AirType：手机语音/文字输入到电脑

1. 双击 AirType EXE。
2. 右键托盘图标，选择“显示手机二维码”或“复制手机网址”。
3. 手机与电脑处于同一可信局域网时，扫码打开手机网页。
4. 在手机输入框中使用豆包输入法、微信输入法或其他你习惯的输入法进行语音/文字输入。
5. 点击手机输入法右下角的“换行”或“确定”，AirType 网页会发送本轮文字；需要真正换行时，请使用网页上的“插入换行”按钮。
6. Windows 收到文字后会粘贴到当前获得焦点的输入位置，并自动模拟按下一次回车。

请先把电脑焦点放到目标输入框。如果目标是 ChatGPT、DeepSeek、豆包等以 Enter 发送消息的 AI 输入框，文字粘贴完成后会被自动发送。程序会在粘贴和自动回车前检查焦点是否仍是原窗口；如果焦点发生变化，会停止后续操作以减少误发风险。不要公开分享二维码或带 Token 的 URL。

## 2. Wireless ADB Tap v1.1.0

适合 Android 11+ 无线调试场景。

1. 让手机和电脑连接同一个局域网，在手机开发者选项中开启“无线调试”。
2. 双击 Wireless EXE；程序会隐藏到系统托盘。
3. 右键托盘图标，选择“二维码配对手机”。
4. 在手机无线调试页面选择“使用二维码配对设备”或名称相近的选项，扫描电脑二维码。
5. 二维码两分钟内有效。程序会自动完成配对、查找连接地址并建立点击通道。
6. 双击托盘图标打开本地设置页面，手动配置并测试三套 `-` / `+` 坐标模式。
7. 保存后，数字小键盘 `-` 与 `+` 可在程序不处于前台时触发对应 Android 坐标点击。

无线配对信息只用于当前设备连接，不应截图公开。

## 3. DirectADB v1.2.0

适合雷电模拟器、其他已接入 ADB 的模拟器或 USB 调试真机。

1. 启动雷电、网易 MuMu 等模拟器并开启 ADB 调试；USB 真机需开启并授权 USB 调试。
2. 双击 DirectADB EXE；程序会隐藏到系统托盘。
3. 右键托盘图标，选择“检测并连接 ADB 设备”。
4. 只有一个可用设备时直接使用；多个设备时双击托盘图标打开设置页面并选择目标序列号。
5. 未找到 ADB 时，在设置页面点击“一次性准备 ADB”，然后重新检测。
6. 手动配置三套点击坐标并测试，保存后使用数字小键盘 `-` / `+` 触发。

DirectADB 不执行无线二维码配对，也不主动运行 `adb connect`。

## 4. 配合 AirType：用 `-` / `+` 完成整套语音输入

ADB Tap 不会把 `-` 和 `+` 写死为某个手机按钮；它们分别点击当前模式中保存的两组坐标。配合 AirType 时可按下面方式配置：

- 把减号坐标设为手机或模拟器输入法的“点击说话/语音输入”按钮。
- 把加号坐标设为手机或模拟器输入法右下角的“换行”或“确定”按钮。

完成配置后：

1. 按电脑数字小键盘 `-`，开始手机/模拟器语音输入。
2. 说完后按电脑数字小键盘 `+`，点击手机输入法的“换行”或“确定”。
3. AirType 网页把这个动作识别为“发送本轮”并发送文字。
4. Windows 端粘贴文字，并在目标窗口焦点未变化时自动按一次回车。

这套方式同时适用于 Wireless 和 DirectADB。Android 真机无线调试使用 Wireless；雷电模拟器或 USB ADB 设备通常使用 DirectADB。

## 5. 雷电模拟器 + 豆包输入法

普通设置页切换第三方输入法时，推荐雷电 9.0.44。另有一套已经实际验证的雷电 9.0.47 Root 方案：Android 分辨率 `1080 × 1920`、DPI `480`，减号参考坐标 `770,1195`，加号参考坐标 `965,1740`。

版本下载、输入法切换、ADB 设备识别、坐标测量及安全注意事项见 [LDPLAYER_DOUBAO.md](LDPLAYER_DOUBAO.md)。
