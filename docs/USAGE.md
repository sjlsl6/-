# Usage

## 1. AirType：手机语音/文字输入到电脑

1. 在 Windows 上启动 AirType。
2. 从托盘打开手机二维码/访问地址。
3. 手机与电脑处于同一可信局域网时，扫码打开手机网页。
4. 在手机输入框中使用你习惯的输入法或语音输入。
5. 发送后，文字写入电脑当前获得焦点的输入位置。

请先把电脑焦点放到目标输入框。不要公开分享二维码或带 Token 的 URL。

## 2. Wireless ADB Tap v1.1.0

适合 Android 11+ 无线调试场景。

- 可通过无线调试二维码流程配对。
- 也可手动填写 ADB 连接地址作为备用。
- 配置三套 `-` / `+` 点击坐标模式。
- 数字小键盘 `-` 与 `+` 触发对应 Android 坐标点击。

无线配对信息只用于当前设备连接，不应截图公开。

## 3. DirectADB v1.2.0

适合雷电模拟器、其他已接入 ADB 的模拟器或 USB 调试真机。

1. 先确认命令行执行 `adb devices` 能看到目标设备且状态为 `device`。
2. 启动 DirectADB。
3. 点击检测/刷新设备。
4. 只有一个可用设备时自动选择；多个设备时选择目标序列号。
5. 配置三套点击坐标并测试。
6. 使用数字小键盘 `-` / `+` 触发。

DirectADB 不执行无线二维码配对，也不主动运行 `adb connect`。
